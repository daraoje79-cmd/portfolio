# Subline bot - 3D Animated Portfolio

A modern, professional 3D animated portfolio website showcasing projects, skills, experience, and blog posts.

## Features

✨ **3D Animations & Effects**
- Interactive 3D card animations
- Smooth transitions and parallax scrolling
- Floating profile image with 3D perspective
- Animated hero section with gradient backgrounds

🎨 **Modern Design**
- Professional color theme
- Clean, minimalist layout
- Fully responsive design
- Smooth navigation with active link highlighting

📱 **Responsive**
- Mobile-friendly interface
- Hamburger menu on smaller screens
- Optimized for all devices

🔧 **Sections**
- Hero section with call-to-action
- About me
- Skills showcase
- Featured projects
- Experience timeline
- Blog articles
- Contact information
- Social media links

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content with your information
4. Deploy to GitHub Pages or your hosting provider

## Deployment to GitHub Pages

1. Go to your repository settings
2. Scroll to "GitHub Pages" section
3. Select the branch containing your files as source
4. Save and your site will be live

## Customization

### Update Your Profile Image
- Replace `profile.jpg` with your image
- Image should be square (recommended: 500x500px)

### Update Your Logo
- Replace `logo.svg` with your logo
- Or modify the SVG directly

### Change Colors
- Edit the CSS variables in `styles.css` `:root` section
- Update the color hex values to match your brand

### Update Content
- Edit the HTML sections in `index.html`
- Update project details, skills, and experience
- Customize social media links
